# HTTPS 证书

1. 准备好的证书文件

   放在项目目录的 ssl

   - 购买
   - 免费申请
   - 自签名证书

   docker run --rm -it -v `pwd`/ssl:/ssl soulteary/certs-maker:v3.8.0 "--CERT*DNS=example.com,*.example.com,\_.data.example.com"

2. 拥有的域名自动申请“Let’s Encrypt”免费证书

# 购买或自签名 HTTPS 证书

    * 拷贝
    cp docker-compose.local-certs.yml docker-compose.yml
    * 启动
    docker compose down && docker compose up -d

    修改系统的 /etc/hosts
    访问: https://traefik.example.com

# 启动 Traefik 并自动申请 HTTPS 证书

    * 拷贝
    cp docker-compose.acme.yml docker-compose.yml
    * 启动
    docker compose down && docker compose up -d

# 快速启动一个服务，注册到 Traefik 上

    docker pull soulteary/flare:0.5.1
    docker run --rm -it -p 5005:5005 soulteary/flare:0.5.1

    用 https://www.composerize.com/
    转换为 Docker Compose 配置文件

    修改为 docker-compose.flare.yml 一样
    启动
    docker compose -f docker-compose.flare.yml up -d

    可以打开
    https://flare.example.com/
